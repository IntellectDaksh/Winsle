Forward phone notifications

Send an HTTP POST from an automation app whenever a notification arrives. Only works while the phone is on the same Wi-Fi as the PC.


    
    

    

    
    
{"app":"WhatsApp","title":"Sender","body":"Message text"}

    
Tasker (Android)
      
Profile → Event → UI → Notification (pick apps). Task → Net → HTTP Request: Method POST, URL above, Headers Authorization: Bearer … and Content-Type: application/json, Body {"app":"%an","title":"%ntitle","body":"%ntext"}. Use Tasker's AutoNotification or the built-in %evtprm variables if %ntitle is empty.

    

    
MacroDroid (Android)
      
Trigger: Notification received (choose apps). Action: HTTP Request → POST, URL above, add both headers, Content body {"app":"[notification_app_name]","title":"[notification_title]","body":"[notification]"}.

    

    
iOS Shortcuts
      
iOS doesn't let apps read other apps' notifications. Use Automation → "When I get a message / email / app opened", then action "Get contents of URL": Method POST, Headers as above, Request Body JSON with keys app, title, body.
